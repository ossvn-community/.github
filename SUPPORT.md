# Support

Nếu bạn chưa biết bắt đầu contribution ở đâu, đọc [START_HERE.md](START_HERE.md).

Nếu task chưa rõ, hỏi ngay trong issue của task đó.

Nếu gặp bug, tạo issue phù hợp.

Không gửi security vulnerability bằng public issue. Xem [SECURITY.md](SECURITY.md).

Trong pilot, OSSVN chưa mở kênh support riêng nếu GitHub Issues đã đủ.
