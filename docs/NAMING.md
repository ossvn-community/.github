# Naming

## Brand

**OSSVN**

Full name: **Open Source Software Vietnam**.

Tên hiển thị có thể dùng:

> OSSVN - Open Source Vietnam

## GitHub

Organization handle chính thức:

```text
ossvn-community
```

Organization:

https://github.com/ossvn-community

Không cần đổi brand chỉ vì handle GitHub không phải `ossvn`.

## Repo naming

Ưu tiên tên ngắn, chữ thường và dùng dấu `-` khi cần.

Ví dụ:

```text
community
it-in-plain-vietnamese
repository-template
rulesets
```

Tên project hiển thị có thể tự nhiên hơn repository slug.
