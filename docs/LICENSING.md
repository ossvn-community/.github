# OSSVN Licensing

Mục tiêu: contributor biết rõ một file có thể được dùng lại thế nào mà không phải đoán.

## Default

OSSVN dùng hai license mặc định:

- Code, scripts, workflows, automation và configuration: **MIT**.
- Documentation, policy, educational content, prose và diagrams: **CC BY 4.0**.

Repo chỉ có software/config có thể chỉ dùng MIT.

Repo có cả code và content có thể dùng:

```text
LICENSE
LICENSE-CODE
LICENSE-CONTENT
```

`LICENSE` giải thích phạm vi. Hai file còn lại chứa điều khoản tương ứng.

## Project hiện tại

- `.github`: CC BY 4.0 + MIT.
- `community`: CC BY 4.0 + MIT.
- `it-in-plain-vietnamese`: CC BY 4.0 + MIT.
- `repository-template`: MIT.
- `rulesets`: MIT.

## Third-party material

Không tự động relicense nội dung hoặc code của bên thứ ba.

Khi dịch, adapt hoặc copy material từ nguồn khác:

1. Kiểm tra license nguồn.
2. Tuân thủ attribution và điều kiện của license đó.
3. Ghi rõ phần nào là third-party material khi cần.

Public trên Internet không đồng nghĩa với được phép copy hoặc relicense.

Đây là policy vận hành của OSSVN, không phải tư vấn pháp lý.
