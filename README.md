# OSSVN .github

Repository mặc định cho GitHub Organization OSSVN.

Repo này chứa policy và community health files dùng chung.

## Chứa gì?

- `profile/README.md` - Organization profile.
- `CONTRIBUTING.md` - quy tắc contribution chung.
- `CODE_OF_CONDUCT.md` - chuẩn hành vi.
- `SECURITY.md` - cách báo cáo vấn đề bảo mật.
- `SUPPORT.md` - nơi hỏi và nhận hỗ trợ.
- `docs/` - policy dùng chung về AI, risk, review và testing.
- `.github/pull_request_template.md` - PR template mặc định.

Repo riêng chỉ override khi thật sự cần rule khác.
