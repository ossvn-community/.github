# OSSVN

**Open Source Software Vietnam**

OSSVN muốn làm open-source dễ bắt đầu hơn cho người Việt.

- Tìm contribution nhỏ để bắt đầu.
- Học công nghệ bằng tài liệu ngắn, dễ hiểu.
- Khám phá các dự án Made in Vietnam.
- Build public goods cùng cộng đồng.

> Low barrier to contribute. High standard to merge.

Bắt đầu tại repo `community`.
