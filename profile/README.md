# OSSVN

**Open Source Software Vietnam**

OSSVN muốn làm open-source dễ bắt đầu hơn cho người Việt bằng cách build những public-good project hữu ích và mở cửa cho contribution.

Chúng tôi bắt đầu đơn giản:

- Build project thật trước.
- Viết tài liệu ngắn, đúng và dễ hiểu.
- AI-assisted và vibecoding contributions được welcome.
- Ai thấy hữu ích có thể dùng; ai muốn đóng góp có thể mở Issue hoặc Pull Request.

## Project đầu tiên

**IT in Plain Vietnamese** - giải thích từng concept IT bằng tiếng Việt đơn giản, trong vài phút đọc nếu có thể.

Bắt đầu tại repo `community` hoặc đi thẳng tới `it-in-plain-vietnamese`.

> Low barrier to contribute. High standard to merge.
